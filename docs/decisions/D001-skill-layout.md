# D001：以技能目录作为仓库根目录

日期：2026-09-30

本仓库交付的是可安装的技能，不是业务应用。根目录的 `SKILL.md` 是唯一入口，
`references/` 放按模式读取的指导，`assets/` 放项目模板，`agents/` 放 Codex 元数据。
因此在治理配置中显式允许这些目录和 `SKILL.md`，并允许用户指定的 `docs/designs/`。
`scripts/` 与 `tests/` 存放安装和校验工具，不人为创建业务模块。

项目自身的文件治理不作为安装到其他项目的强制目录规范；已有项目保留自己的布局。
技能安装只复制技能运行所需文件。根据用户追加的分层要求，默认使用用户级
`~/.agents/skills/code-design-planner/`；项目只保存项目知识，不复制技能。
显式选择安装全局规则后才合并全局 AGENTS.md；本次仓库构建不自动安装额外插件或改写全局配置。
